# 接线说明

所有信号线都是 3.3V 电平逻辑。HC-SR04 是唯一需要电平处理的模块。

## 引脚分配

| 模块 | 信号 | 接到 | 说明 |
|---|---|---|---|
| HC-SR04 | VCC | 5V（VBUS） | 3.3V 带不动发射端，实测 Echo 锁死 |
| HC-SR04 | Trig | GPIO30（丝印 D13） | 板子输出 3.3V，模块 >2V 判高，直连 |
| HC-SR04 | Echo | **分压后** → GPIO31（丝印 D10） | 模块回波 5V，直灌顶穿 3.3V GPIO |
| HC-SR04 | GND | GND | 共地 |
| RGB LED | R / G / B | GPIO32 / 4 / 5 | 共阳，低电平点亮 |
| 蜂鸣器 | SIG | GPIO6 | 套件低电平触发 |
| 心跳灯 | SIG | GPIO7 | — |
| AHT20 | SDA / SCL | I2C0 | 温湿度，声速补偿用 |
| AHT20 | VCC / GND | 3V3 / GND | — |

## Echo 分压（数字信号，要快）

```
Echo ──┬── 1kΩ ──┬── GPIO31
       │         │
       └── 2kΩ ──┴── GND
```

取小阻值（分压比 0.667，5V→3.33V）是为了边沿陡。GPIO 输入电容约 10pF，
RC 时间常数纳秒级，脉宽测量不受影响。分压电阻必须插面包板或焊死，
杜邦线夹电阻腿一晃就断，症状是读数随机跳变。

## 常见误接

- Echo 直连 GPIO：读数乱跳、攒不满连续 8 帧有效回波 → 链路激活不了
- Trig / Echo 插反：读数恒定或乱跳
- VCC 接 3.3V：发射能量不足，回波极弱
- 对着吸音物或超 450cm：一直无有效回波（不是坏了，HC-SR04 稳定上限 450cm）
