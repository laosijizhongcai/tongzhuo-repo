# 报名表 · 作品名称及创意简介（项目一「同桌」）

> 用途：What If Lab 黑客松报名表「作品名称及创意简介」栏直接粘贴文本。
> 口径：型号 EC800 系列、只称"云端大模型"不点厂商、含台灯场景亮点。
> 字数：正文约 299 字（报名表要求 100–300 字）。

---

「同桌」是一台只认距离的桌面装置。115 厘米外它装死，只剩省略号；走进 95
厘米给一句没说完的钩子；凑进 38 厘米才肯说出完整答案，外加行为点评——路过、
试探还是赖着不走，它从轨迹里判出来，由云端大模型现场写词。退开一步，话当面被切断。

它要解决的是：当所有内容零成本可得，就没有内容值得人走过去。把门槛设回身体的距离，
注意力才真的发生。

硬件为移远 QuecDuino（EC800 系列）加 HC-SR04 超声，4G 直连云端。妙在固件的会话状态机
本就按学习场景设计——同一套逻辑装进孩子书桌那盏 3D 打印台灯，不拍照片就能统计学习
时长、趴桌时提醒坐直。它始终不知道你是谁，只知道你有多近。
